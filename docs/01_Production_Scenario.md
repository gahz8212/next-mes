# [SMT 전 공정 실전 데이터 흐름 시나리오]

1. **사전준비:** BOM 업로드 -> 작업지시(WO) 생성 -> 바코드 일괄 발행
2. **라인 할당:** 작업지시를 특정 라인에 할당 (`line_status` 업데이트)
3. **스마트 포카요케 (MSL 통제):** 피더 자재 스캔 -> BOM 비교 & MSL 자동 개봉/검증 -> 통과/차단
4. **SMT 실장(Top/Bottom):** Node-RED 감지 -> 재고 백플러싱 차감 및 이력 기록
5. **수삽/웨이브:** 태블릿 작업 지시 및 Node-RED 온도 센서 감시
6. **검사(ICT/FCT):** 검사 PC csv 감지 -> Node-RED -> PHP 테스트 결과 전송
7. **출하:** 최종 스캔 및 ORCA 대시보드 실시간 반영
